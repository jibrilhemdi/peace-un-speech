# Conference reuse notes

This repository maintains one paper source, `main.tex`. The present anonymous
two-column ACM layout is the WebSci full-paper draft. Venue-specific copies,
metadata, and page counts should be checked when each submission is prepared.
Introduction and Literature Review remain placeholders; the other sections
are drafted, and human assessment has not been returned. CCS concepts and
the ACM Reference Format block are included. Publication identifiers and
rights metadata await the actual ACM acceptance workflow.

| Venue | Current public requirements | Implication for this draft |
| --- | --- | --- |
| [WebSci 2027](https://websci27.webscience.org/call-for-papers/) | Full papers are 6–10 pages, **including references and appendices**, in two-column ACM format with anonymous review. | The current PDF is seven pages; Introduction, Literature Review, and validation findings still need space. A credible contribution about the Web must be developed; fit is conditional. The author intends the WebSci proceedings publication option. |
| [IPSA 2027](https://wc2027.ipsa.org/wc/submit-paper) | The first submission is a proposal abstract of at most 350 words. A later full paper may be up to 25 single-spaced pages. | Prepare a separate proposal abstract first. Reuse the research argument and evidence later, adapting the paper format and length to IPSA instructions. |
| [EPSS 2027](https://epssnet.org/2027-copenhagen/call-for-papers-2/) | The current Copenhagen call states no paper page cap. The [linked FAQ URL](https://epssnet.org/conferences/epss-2027-sf/) currently displays a Belfast 2026 FAQ, so it should not be treated as 2027 guidance. | Check any later submission-system instructions before sending a full paper; no cap is asserted here. |

Before submitting overlapping versions to later conferences, check their
originality, prior-publication, and proceedings policies against the intended
WebSci proceedings publication. No submission has been made from this repository.
